# Contributing to Nitrate

Thank you for your interest in contributing to **Nitrate**!

## Core Principles
1. **Zero External Python Dependencies**: Nitrate must stay runnable out of the box on any machine with Python standard library.
2. **Audio/Video Fidelity First**: We prioritize uncompressed, mathematically exact rendering via MPV + `libplacebo`.
3. **Speed & Minimalism**: The terminal UI must stay lightning fast and responsive.

## Development Setup
```bash
git clone https://github.com/Manteh/nitrate.git
cd nitrate
python bin/nitrate "Inception"
```
